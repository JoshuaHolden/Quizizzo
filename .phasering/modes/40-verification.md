# Verification Phase

This phase checks whether the implementation meets its goals, prioritizing verification and issue reporting without expanding scope.

## Codex responsibilities

- Check critical flows, edge cases, and failure paths.
- Distinguish verified facts, hypotheses, and uncovered areas.
- Report the acceptance result first; fix discovered issues only when the user asks.
